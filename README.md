# 穿搭助手（v1）

手机优先的本地网页应用：拍照建衣橱（上衣/裤子/鞋子），每天按天气和规则给 2–3 套穿搭候选，记录穿着，一键导出备份。数据全部存在本机浏览器，不上传任何服务器。

## 文件结构

```
E:\outfit\
├── index.html      页面骨架
├── style.css       样式（移动优先）
├── app.js          全部逻辑（存储/取色/打分/推荐/导出）
├── sw.js           Service Worker（离线缓存应用壳）
├── manifest.json   PWA 清单（加到主屏幕用）
└── icons\          应用图标
```

## 本地运行

```bash
cd E:\outfit
python3 -m http.server 8077
```

浏览器打开 http://127.0.0.1:8077 （电脑上先试功能、建测试数据都从这里进）。

> 双击 index.html（file:// 方式）大部分功能也能用，但 Service Worker 和分享面板需要 http(s)，建议还是起个本地服务。

## 手机上用（正式使用）

两步：

1. **部署到一个 HTTPS 地址**（免费静态托管即可，应用是纯静态文件）：
   - GitHub Pages / Cloudflare Pages / Netlify 任选，把 `E:\outfit` 整个目录推上去就行；
   - HTTPS 是硬要求：iPhone 的分享面板（导出到微信）只在 https 或 localhost 下可用。
2. **加到主屏幕**：Safari 打开网址 → 分享按钮 → 「添加到主屏幕」。
   - 这步不是可选项：iOS 对没装到主屏幕的网站有「7 天不用就清存储」的策略，装了才豁免。

临时应急（同一 Wi-Fi，不部署也能用）：

```bash
# 查看电脑局域网 IP
ipconfig | grep "IPv4"
# 启动服务（允许外部访问）
python3 -m http.server 8077 --bind 0.0.0.0
```

手机浏览器打开 `http://<电脑IP>:8077`。注意 http 下导出走「下载」而不是分享面板，日常用还是建议 https。

## 日常用法

1. **建库**：「衣橱」→「＋ 添加衣物」→ 拍照（拍平整、光线均匀，取色更准）→ 自动识别主色，不对就点色卡改 → 选子类型（自动带出适穿温度和正式度默认值）→ 起个名字 → 保存。
2. **每天穿**：「今天」页自动取天气（wttr.in，可手动改温度）→ 选场合（通勤/休闲/运动/正式，工作日默认通勤）→ 出 3 套候选，每套带一句话理由 → 点「就穿这套」自动记为今天穿的；不合适点 👎，喜欢点 👍。
3. **新购**：随手拍一张加进库。
4. **换季/穿坏**：编辑衣物改状态（在洗/收纳/退役），推荐自动跳过。

## 备份（重要）

数据在浏览器里，**清浏览器数据 = 全没**（iPhone 加主屏幕后 Safari 的清除按钮碰不到它，但删图标、换手机会没）。所以：

- 「设置」→「导出备份」：打包整个库（照片+记录）成一个 zip；
- iPhone 上分享面板里直接发给**微信「文件传输助手」**（电脑微信也能收，等于异地备份），或存到「文件」App；
- 「导入恢复」：拿 zip 一键还原；
- 应用会在超过 14 天没备份时在顶栏亮红点提醒。

## 打分规则（推荐的"脑子"）

温度是硬过滤（超出适穿区间直接出局），然后打分排序：

- **正式度一致**：一套里三件的 1–5 级差距越小越好（运动鞋配西裤就是这条扣的）；
- **色彩三原则**：全身 ≤3 色；中性色（黑/白/灰/藏青/牛仔蓝/卡其/米/驼/棕）互搭安全；彩色只配中性色或同色系；鞋色顺色呼应加分；
- **裤×鞋类型矩阵**：西裤+皮鞋高分、西裤+跑鞋低分，一张小查表；
- **风格标签**：重合加分，运动×商务冲突扣分；
- **轮换**：很久没穿的加分，避免天天推同几件；
- **反馈**：👍/👎 直接作用在这套组合上，越用越准；
- 最后加一点随机，别天天一样。三套候选之间强制至少换两件，保证有的挑。

## 技术说明

- 照片：IndexedDB（Blob），录入时压缩到长边 720px / JPEG 0.82，一件约 50–100KB；
- 记录：localStorage；
- 天气：wttr.in（国内可达、支持跨域），失败自动尝试 open-meteo，再失败用手动温度；
- 导出：纯 JS 生成 zip（store 模式 + CRC32），无任何第三方库；
- 离线：Service Worker 缓存应用壳，网络优先、断网兜底。
